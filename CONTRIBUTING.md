# Contributing

Build, test and commit conventions are in [CLAUDE.md](CLAUDE.md); the board, labels, triage and the week's rhythm in [shakvalang's CONTRIBUTING](https://github.com/shakvalang/.github/blob/master/CONTRIBUTING.md). What the docs are and when a change writes there: [docs/README.md](docs/README.md).

A change to the language is two things in one PR: its spec and the code that implements it, with a snapshot test of what the compiler says about it. Where the spec lives is decided by the first slice that writes one.
