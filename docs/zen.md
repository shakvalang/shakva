# The Zen of Shakva

The Zen of Shakva captures the guiding principles for Shakva language design. Every language feature, syntax decision, and design choice must follow them.

When in doubt, refer back to these principles. If a feature contradicts them, the feature is wrong, not the principles.

```text
Common code needs little ceremony.
Types are inferred when obvious and explicit when useful.
Different syntax should express different intent.
Expressions compose; statements remain straightforward.
Syntax has predictable boundaries.
```
